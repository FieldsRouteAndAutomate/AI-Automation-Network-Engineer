# Workplace Support Agent

## Purpose

Provide self-service assistance for common support issues.

## Supported Topics

- Software Center
- SCCM
- Intune
- Microsoft Teams
- Windows 11
- Dell Devices

## Example Questions

- Why is my Wi-Fi disabled?
- How do I clear SCCM cache?
- How do I install software from Software Center?
- How do I reconnect to VPN?

## Expected Benefits

- Fewer support tickets
- Faster issue resolution
- Improved employee experience
